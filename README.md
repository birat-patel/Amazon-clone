# Amazon-clone

This is a **fully responsive Amazon Clone website** built using **HTML, CSS, and JavaScript**.  
It recreates the UI design and layout of the Amazon India homepage with smooth interactions and clean styling.


## Features
✅ Responsive layout (works on desktop, tablet & mobile)  
✅ Interactive sidebar menu with toggle feature  
✅ Top navigation bar with logo, search, cart, and account sections  
✅ Product categories, banners, and deal sections  
✅ Smooth hover effects and animations  
✅ Clean and modern design inspired by Amazon  


## Technologies Used 
| **HTML5** | Structure and content |
| **CSS3** | Styling and responsive design |
| **JavaScript (ES6)** | Dynamic sidebar and interactivity |
| **Font Awesome** | Icons for UI elements |
